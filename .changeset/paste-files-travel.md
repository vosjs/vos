A pasted file travels with its take. `vos push` sends every file the take's `actions.json` pastes and lists them on the document as `source.scriptFiles` (the name the script pastes it by → where its bytes are): a picture through the same upload door as every other file the document names, a text file inside the document as a `data:` address (at most 256 kB). `vos fetch --media` and `vos pull --media` write each one back beside `actions.json` under that name, never over a file already there, and record a hosted one in `vos.json` like the footage, so a fetched take records again from anywhere. Only a name the document's own script pastes is written, and only from the platform's file door or the document itself. A paste file the take does not hold is said and left out; one that resolves outside the take directory is refused before anything is sent (exit 2). A claimable push carries a pasted text file and a pasted picture the take fetched unchanged, and says what it leaves out. A drag's `path` file needed nothing: the take's script already carries its points inline. The recorder's message for a missing paste file says the fetch now brings it.
