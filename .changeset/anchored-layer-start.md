An overlay with an `anchor` needs no `start`: the anchor places it, and `start`, when given, stays the fallback. `OverlayClip.start` is optional in the type. A layer whose anchor resolves nowhere and that has no start is left out of the lowering (never placed at 0), and `vos validate` refuses it, naming the step; the lanes, the still, the output length, pins, `vos join`, `vos plan --reuse` and the ground check read where the step plays. `layerStart` answers a layer's start as the document stands, and `bakeDocFeatures` writes the resolved start for a renderer that predates the field.
